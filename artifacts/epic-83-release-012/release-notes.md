# ЛОТ Closed Alpha 0.1.2 — First Supported Release

## Что нового

- **First supported Closed Alpha baseline** (`minimumSupportedVersionCode = 3`)
- Mobile UX Wave 1/2
- Seller product navigation fix
- New design system
- Improved catalog / PDP
- Startup timeout + retry
- Unsupported client screen for obsolete versions
- Update-flow hardening (boot pipeline + telemetry)
- Orange LOT launcher icon and branded splash
- Real bottom-nav icons, product images, 2-column catalog
- Buyer home sections, seller dashboard, wallet layout
- Russian statuses and improved empty/loading states
